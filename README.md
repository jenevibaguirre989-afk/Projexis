# 🚀 Projexis | VA & Freelancer Vault

**Projexis** is a lightweight, responsive, and secure Web-based Dashboard designed specifically for Virtual Assistants (VAs) and Freelancers. Built as a Single Page Application (SPA), it enables users to track project timelines, store client information, attach file outputs directly as Base64 data, maintain a prioritized schedule queue, and securely manage client credentials.

---

## ✨ Features

- **🔐 Firebase Cloud Authentication**
  - Real-time login and registration with email and password.
  - Multi-user isolation — each user only accesses their own project data and vault items.
- **📊 Comprehensive Dashboard Overview**
  - High-level project and task analytics.
  - Total budgeted value calculator for tracked active projects.
- **📁 Projects & Files Management**
  - Track active projects with statuses (*Planning*, *In Progress*, *Completed*).
  - Attach and re-download deliverables/file outputs via embedded Base64 strings.
- **👥 Clients Directory**
  - Centralized database for managing client contact info and company profiles.
- **📅 Schedule & Priority Queue**
  - Interactive milestone tracker sorted by due dates with interactive task completion toggles.
- **🛡️ Secure Vault & Credentials Locker**
  - Encrypted-style storage for client login portals, passwords, and sensitive notes.
- **📱 Fully Responsive UI**
  - Modern, dark-themed glassmorphism interface powered by CSS CSS3 custom variables and FontAwesome icons.

---

## 🛠️ Tech Stack & Technologies Used

- **Frontend Framework:** HTML5, CSS3, JavaScript (ES6 Modules)
- **Design System:** Glassmorphism, Google Fonts (`Plus Jakarta Sans`), FontAwesome 6.4.0
- **Backend / BaaS:** Google Firebase Web SDK v13.1.0
  - **Firebase Auth:** Handles user authentication state.
  - **Firestore Database:** Cloud NoSQL database for real-time document storage.

---

## 🚀 Getting Started

Since Projexis is completely self-contained in a single file, setup is minimal!

### Prerequisites

All you need is a modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari) and an internet connection to connect to Firebase.

### Installation & Local Run

1. **Clone or Copy the repository code:**
   Save the code as `index.html` on your computer.

2. **Run locally:**
   - Double-click `index.html` to open it directly in your web browser, **or**
   - Serve it using VS Code's **Live Server** extension for an optimal local development environment.

3. **Log in or Register:**
   - Create a new account using your email address and password.
   - Once logged in, your session persists automatically through Firebase Authentication.
